## 기본 연동

원본 YOLOv5 v7.0과 공식 가중치 해시를 확인하고 사람 4명과 버스 1대를 검출했다. 첫 출현과 연속 장면 및 재등장에 따른 등록을 검증했다. 로컬 API 및 사진 목록, Android와 모바일 웹의 같은 검출 사진 조회를 확인했다.

PythonAnywhere의 기존 실제 YOLO 등록 게시글은 8번이다. 11월 10일 본인 웹캠에서는 9번이 자동 등록됐고 화면 이탈 및 재진입 시험에서 12번부터 14번이 추가 등록됐다. 9번과 12번부터 14번의 서버 파일은 각각 전송 JPEG와 SHA256이 일치했다. 이동 중 잠깐의 검출 소실로 13번이 추가 등록된 사례를 보존했고 이를 방문 횟수로 계산하지 않는다. 운영 Android 네이티브 앱에서도 9번과 14번 사진의 지문과 목록 및 상세를 확인했다. 기존 기본 주소창 캡처는 evidence/screenshots/basic-20261110, 추가 증빙은 evidence/screenshots/self-flow-20261110 및 self-native-20261110에 있다.

11월 10일 노트북의 Acer HD User Facing 웹캠을 USB/IP로 WSL2 Ubuntu에 연결했다. 실제 /dev/video0를 MJPEG로 읽고 수정하지 않은 원본 검출기로 사람을 검출했다. person 0.71 출력 프레임과 원시 검출값, 원본 해시 및 로그를 확보했다. 전달 파일 18개의 SHA256이 모두 일치했다. 증빙은 evidence/notebook-20261110과 보고서 B08이다.

## 공개 접근과 AI 한도

관측과 얼굴 사진 조회 및 AI 질문은 로그인 없이 이용한다. 대화는 계정 또는 방문자 브라우저 세션별로 분리한다. 인물 확인 저장과 프로필 및 사진 변경은 지정 운영자 권한을 유지한다. 로그인 시도 제한은 사용자 승인에 따라 해제했다. 질문과 대화 생성의 CSRF 검증은 유지한다.

AI 설명은 서버 전체 하루 5회, 임베딩은 하루 100회다. 한국 시간 자정에 새 날짜의 한도를 적용하고 실제 외부 요청 시도를 집계한다. 카운터는 비공개 SQLite에 유지한다. 상태를 조회하지 못하면 유료 호출을 차단하며 캐시와 대화 복원은 새 호출로 집계하지 않는다. 최신 서버 전체 302개와 웹 76개가 통과했다. 서로 다른 방문자 6명의 요청에서 외부 생성 요청 5회만 허용하는 모의 검사를 포함한다.

11월 10일 공식 API 인증으로 운영에 반영하고 공개 URL을 별도로 확인했다. 공개 접근 및 한도 정책 배포 시의 사용량 0회 기록은 evidence/security/deployment.json에 남아 있다. 이후 본인 기록 검증에서 승인된 생성 요청 4회를 사용했으므로 해당 0회는 현재 사용량이 아니다. 최신 배포는 20261110120957270ef6이며 소스 지문과 실제 응답을 확인했다. 증빙은 evidence/ui-audit/self-guards-deployment-20261110.json이다. API 요청은 최소 5초 간격으로 유지하고 모델 호출을 자동 반복하지 않았다. DB 스키마와 기존 자료는 유지했다.

## 추가 기능

Edge 인물 추적과 관측 기록 전송, Server 인물 이력과 근거 기록 질의 두 항목이다. 검출 박스, 운영자 확인, 날짜별 이력, 임베딩 검색, 실제 LLM 답변 및 대화 복원이 같은 서비스에서 연결된다.

11월 9일 운영 검증에서 사진 500장, 분석 실행 및 임베딩 문서 각각 40개를 확인했다. ChokePoint 등록 인물은 29명, 전체 갤러리는 34명이다. 일반 구간 정답 대응 359건 중 후보 일치 358건, 보류 1건과 오연결 0건이었다. 검출 표본의 결과이며 전체 검출률과 구분한다. 같은 영상의 재분석은 원본 영상 수에 중복 집계하지 않고 후보와 확인을 구분한다.

본인 촬영 문서 3개와 고정 질문 3개를 임베딩 1회로 처리했으며 533토큰을 사용했다. 기존 벡터를 유지해 색인 문서는 43개다. 인물과 날짜의 실제 DB 검사 5개 및 캐시 전용 의미 검색 3개를 확인했다. 모자 착용과 재진입 조건은 촬영 설명 메타데이터로 범위를 제한한다. 복장을 사진에서 자동 분류한 기능과 구분한다. 최종 모자 질문은 출처 1개와 근거 사진 1개만 반환했고 실제 생성 내용도 일치했다. 실패 및 범위 오류가 있던 앞선 시도는 덮어쓰지 않았다. 근거는 evidence/history/self-rag-20261110.json이다. 고정 예제와 반복 프레임의 결과를 일반 인식이나 임의 질문의 정확도로 확대하지 않는다.

## 제출

필수 폴더는 PhotoBlogServer, PhotoViewer, YOLOv5이며 보고서는 루트에 둔다. 공통평가 02 전용 저장소는 https://github.com/haddol7/mobile_web_service_02 이다. evidence/github-upload.json과 evidence/github-final-report.json은 이전에 검증한 커밋의 기록이다. 이번 본인 웹캠 보완본은 사용자 제외 범위인 6번에 따라 커밋 및 푸시하지 않았다. 최신 로컬 보고서를 이전 원격 보고서와 동일한 것으로 설명하지 않는다.
