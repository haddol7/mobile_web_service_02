# 공통평가 02 검증 현황

2026년 11월 5일 기준이다. 완료 여부는 `assessment-requirements.json`과 보고서의 평가표에 함께 기록한다.

## 확보한 결과

수정하지 않은 YOLOv5 v7.0 검출기로 공식 bus.jpg를 실행해 사람 4명과 버스 1대를 검출했다. 원본 detect.py와 모델 파일은 공식 파일의 SHA256을 대조했다. 서버 전송을 연결한 검출기는 첫 출현과 재등장에서 각각 게시글을 만들고 동일 장면에서는 추가 전송하지 않았다.

별도 임시 DB에서 실제 영상 30프레임을 입력했을 때 게시글은 총 2개였다. 각 사진의 크기는 320 x 240이었다. 잘못된 인증값으로 전송하면 서버가 거부하고 게시글은 추가되지 않으며 실패한 사진은 로컬에 남았다. 클라우드 검사 도구의 등록 및 기존 게시글과 사진 보존 검사도 이 임시 서버에서 통과했다. 이 결과를 PythonAnywhere 검증으로 집계하지 않는다.

WSL Django 전체 테스트 148개와 Edge 단위 테스트 8개가 통과했다. HTTP 15개는 전체 148개 중 별도 엔진에서 다시 실행한 사례다. Windows Android 단위 테스트 38개, Lint 오류 0개와 경고 7개를 확인했다. 에뮬레이터의 실제 앱과 Chrome에서 검출 사진의 목록 및 상세 화면을 캡처했다. 앱 검사는 API 이미지의 SHA256과 검출기가 등록한 사진의 SHA256을 비교한다.

전용 WSL 가상환경에서 pip check, OpenCV 로딩, PyTorch CPU 연산이 통과했다. 재현 명령은 저장소 README에 정리했다.

## 남은 평가 항목

- 3번 웹캠 실행 실측: Windows 연결 카메라 0개이며 WSL에도 영상 장치가 없다. 정지 사진과 생성 영상 검증은 완료했지만 웹캠 증빙은 별도로 필요하다.
- 8번과 9번 PythonAnywhere: 02 소스 전환을 승인받았으나 Bash 콘솔 API가 HTTP 412를 반환해 배포 시작 전에 멈췄다. 운영 소스는 기존 경로를 유지한다. 게시글 업로드용 앱 API 인증도 별도 제공이 필요하다.
- 10번 추가 편의 기능: 사용자 지시에 따라 기본 기능 검증 후 최대 2개를 별도로 선정한다.

기존 운영 서버와 후보의 API, 모델, 마이그레이션 관련 16개 파일은 읽기 전용으로 비교해 일치했다. 이 비교를 배포나 운영 검증 완료로 처리하지 않는다.

보고서는 현재 진행본이다. 웹캠과 02 클라우드의 요구 환경에서 증빙을 확보한 뒤 해당 항목을 갱신한다.
