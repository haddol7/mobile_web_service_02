## 기본 연동

원본 YOLOv5 v7.0과 공식 가중치 해시를 확인하고 사람 4명과 버스 1대를 검출했다. 첫 출현과 연속 장면 및 재등장에 따른 등록을 검증했다. 로컬 API 및 사진 목록, Android와 모바일 웹의 같은 검출 사진 조회를 확인했다.

PythonAnywhere의 실제 YOLO 등록 게시글은 8번이다. 기본 API HTTP 200, 브라우저 사진 목록과 상세, Android 이미지 해시와 표시를 확인했다. 11월 10일에는 로그인하지 않은 Android Chrome에서 운영 API, 목록과 상세의 주소창을 포함해 다시 캡처했다. 기존 게시글과 계정 및 사진은 보존했다. 최신 기본 캡처는 evidence/screenshots/basic-20261110, 검증 기록은 evidence/basic-verification-20261110에 있다.

11월 10일 노트북의 Acer HD User Facing 웹캠을 USB/IP로 WSL2 Ubuntu에 연결했다. 실제 /dev/video0를 MJPEG로 읽고 수정하지 않은 원본 검출기로 사람을 검출했다. person 0.71 출력 프레임과 원시 검출값, 원본 해시 및 로그를 확보했다. 전달 파일 18개의 SHA256이 모두 일치했다. 증빙은 evidence/notebook-20261110과 보고서 B08이다.

## 공개 접근과 AI 한도

관측과 얼굴 사진 조회 및 AI 질문은 로그인 없이 이용한다. 대화는 계정 또는 방문자 브라우저 세션별로 분리한다. 인물 확인 저장과 프로필 및 사진 변경은 지정 운영자 권한을 유지한다. 로그인 시도 제한은 사용자 승인에 따라 해제했다. 질문과 대화 생성의 CSRF 검증은 유지한다.

AI 설명은 서버 전체 하루 5회, 임베딩은 하루 100회다. 한국 시간 자정에 새 날짜의 한도를 적용하고 실제 외부 요청 시도를 집계한다. 카운터는 비공개 SQLite에 유지한다. 상태를 조회하지 못하면 유료 호출을 차단하며 캐시와 대화 복원은 새 호출로 집계하지 않는다. 기존 250개 대비 33개 사례가 추가된 전체 283개, 웹 76개와 배포 범위 검사 3개가 통과했다. 서로 다른 방문자 6명의 요청에서 외부 생성 요청 5회만 허용하는 모의 검사를 포함한다.

11월 10일 기존 공식 API 인증으로 운영에 반영하고 공개 URL을 별도로 확인했다. 운영 조회에서 하루 생성 한도 5회와 사용량 0회, 로그인 제한 해제를 확인했다. API와 프로그램 검증 요청은 최소 5초 간격으로 보냈고 동시 접속이나 빠른 반복 확인은 하지 않았다. 기존 자료와 DB 스키마 및 의존성은 유지했다. 이번 작업의 유료 모델 호출은 0회다. 정책은 docs/security-controls.md, 실제 운영 릴리스와 확인 시점은 evidence/security/deployment.json에 있다.

## 추가 기능

Edge 인물 추적과 관측 기록 전송, Server 인물 이력과 근거 기록 질의 두 항목이다. 검출 박스, 운영자 확인, 날짜별 이력, 임베딩 검색, 실제 LLM 답변 및 대화 복원이 같은 서비스에서 연결된다.

11월 9일 운영 검증에서 사진 500장, 분석 실행 및 임베딩 문서 각각 40개를 확인했다. ChokePoint 등록 인물은 29명, 전체 갤러리는 34명이다. 일반 구간 정답 대응 359건 중 후보 일치 358건, 보류 1건과 오연결 0건이었다. 검출 표본의 결과이며 전체 검출률과 구분한다. 같은 영상의 재분석은 원본 영상 수에 중복 집계하지 않고 후보와 확인을 구분한다.

기존 실제 LLM 생성과 임베딩 호출은 승인된 실행 기록으로 보존한다. 이번 기본 문항 보완과 보고서 검수에서는 유료 AI API를 호출하지 않았다. 고정 질문 예제와 반복 프레임의 결과를 전체 방문 인식이나 임의 질문의 정확도로 확대하지 않는다. 근거는 evidence/history, evidence/ui-audit와 docs/testing에 있다.
