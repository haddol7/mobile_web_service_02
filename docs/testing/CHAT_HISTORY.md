# AI 질문 대화 기록

웹과 Android의 AI 질문 화면은 입력창, 보내기, 새 대화, 대화 기록으로 구성했다. 인물과 날짜 조건은 검색 범위 창에서 지정한다. 질문과 답변은 같은 화면에 이어서 표시하고 근거 사진을 누르면 해당 영상 기록을 연다. 모바일에서는 키보드가 열린 높이에 맞춰 대화 영역만 줄이고 보내기 버튼은 화면 안에 유지한다.

글꼴은 Pretendard 1.3.9의 가변 글꼴을 웹과 Android에 포함했다. 웹은 같은 서버에서 WOFF2를 제공하고 Android는 앱 자산의 TTF를 읽는다. 시스템에 글꼴을 설치할 필요가 없다. 원본 출처는 [Pretendard 공식 저장소](https://github.com/orioncactus/pretendard/tree/v1.3.9)이며 SIL Open Font License 1.1 전문을 두 자산 경로에 포함했다.

## 저장과 복원

대화는 기존 비공개 관측 저장 경로 아래 .question-chats.sqlite3에 저장한다. Django 기본 DB와 사진을 변경하지 않는다. 배포 릴리스 외부의 공유 저장 경로이므로 서버 소스를 갱신해도 대화가 남는다. 대화마다 소유자, 제목, 시간과 질문별 요청 번호, 처리 상태, 검색 조건, 답변, 근거를 저장한다. 서버에서 소유자를 검사하며 다른 계정의 대화는 404로 처리한다.

대화 목록은 20개씩, 이전 질문은 30개씩 불러온다. 오래된 기록을 자동 삭제하지 않는다. 새 대화는 기존 대화를 보존하고, 질문을 처음 보낼 때 생성한다. 웹의 대화 주소와 Android에 저장된 마지막 대화 번호로 같은 대화를 다시 연다. 답변을 다시 읽는 과정에는 모델 호출이 없다.

전송마다 UUID 요청 번호를 사용한다. 같은 대화에 같은 번호와 내용이 다시 들어오면 저장한 결과를 반환한다. 처리 중인 번호나 내용이 달라진 번호로 다시 유료 요청을 실행하지 않는다. 채팅 처리 중에는 운영자 단위 잠금으로 동시에 다른 유료 질문이 실행되지 않도록 하고, 답변이 끝나면 잠금을 풀어 바로 후속 질문을 받는다. 대화 번호가 없는 기존 API의 5초 제한은 유지한다. 연결 오류가 나면 저장된 응답 확인을 제공하며 모델 요청을 자동 재시도하지 않는다.

## 문맥과 비용

운영자는 2026년 11월 9일 앱에서 직접 보내는 질문의 자동 임베딩과 AI 답변 사용을 승인했다. 이 승인은 Codex의 유료 테스트에는 적용하지 않는다. 입력창 아래 API 사용료 안내를 표시한다. 페이지와 대화 기록 조회, 예시 질문 선택, 검색 범위 변경은 무료인 서버 조회만 사용한다.

이어지는 질문에는 서버가 저장한 최근 질문 3개와 답변을 문맥으로 제공한다. 이전 대화에 나온 수치로 새 집계를 검증하지 않는다. 답변의 횟수와 날짜는 현재 조회한 DB 근거로 검증한다. '그 영상', '그중' 등의 후속 질문은 직전 근거 영상 범위에서 다시 조회하고 새 질문 임베딩을 생략한다. 일반적인 모든 대명사를 해석하는 기능을 보장하지는 않는다.

## 검증 자료

WSL의 Django 테스트는 저장, 소유권, 중복 전송, 실패 상태, 페이지 나누기, 후속 질문 범위와 이전 대화 수치의 혼입 방지를 검사한다. Node 테스트는 검색 조건과 요청 번호 및 대화 병합을 검사한다. Android 에뮬레이터에서는 네이티브와 WebView를 두 화면 크기로 실행하고 입력, 후속 질문, 새 대화, 기록 복원과 키보드 상태를 캡처한다. 이 테스트 서버는 모델 응답을 고정하고 외부 전송을 차단한다.

운영 검증 도구 tools/deployment/verify_chat_cloud.py는 이미 승인되어 캐시에 있는 질문만 사용한다. cache_only:true와 generate:false로 저장과 복원, 중복 요청, 근거 범위를 검사하며 새로운 임베딩이나 AI 생성 요청은 하지 않는다. 실제 생성 모델의 품질을 이 저장 검증 결과로 주장하지 않는다.

최종 실행 결과는 evidence/content/server/verification.json, evidence/content/android/verification.json, evidence/mobile-web/unit-verification.json, evidence/ui-audit/after.json, evidence/ui-audit/chat-cloud.json 및 evidence/ui-audit/chat-deployment.json에서 확인한다. 이 문서는 구현 메모이며 제출 보고서 본문과 캡처 편집은 별도 작업이다.

2026년 11월 9일 최종 확인에서 WSL Django 테스트 244개와 로컬 HTTP 검사 15개, 웹 단위 테스트 76개, Android JVM 테스트 40개가 통과했다. Android lint 오류는 0개이며 기존 경고 9개가 남아 있다. 작은 화면과 일반 화면에서 각각 네이티브와 WebView의 대화 전송, 후속 질문, 새 대화, 새로고침과 기록 복원 및 키보드 상태를 캡처했고 기존 사진 작성 흐름도 통과했다. 운영 릴리스 20261108194952368451의 파일 해시와 공개 자산을 확인했다. 운영 서버에 질문 두 개를 저장하고 별도 연결에서 복원했으며 동일 요청의 중복 저장도 방지했다. 운영 브라우저의 새 대화와 기록 목록 및 복원 화면을 별도로 저장했다. 이번 작업의 실제 임베딩과 LLM 생성 API 호출은 0회다. 요약과 화면 해시는 evidence/ui-audit/chat-summary.json에 기록했다.
