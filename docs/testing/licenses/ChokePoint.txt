Project derivative notice
The MP4 clips are reconstructions of available original JPEG frames at 30 fps.
The first1200 clip uses the first 1200 available images, which include gaps in the original frame numbering.
Replay seconds are positions in this reconstructed clip, not original capture times.
Preview and uploaded observation images have been JPEG-compressed.
Source images, raw clips, and derived clips are kept outside Git. Selected observations are accessible only to the authenticated project operator.

Additional portal recordings
P1E_S2_C2, P1L_S1_C1, P2E_S5_C2, and P2L_S5_C2 are reconstructed from all available original JPEG images for each selected camera.
The image-to-replay-position mapping is retained beside each private derivative. Gaps in the original image numbering are not claimed to be continuous original capture time.
Selected observations are time-spread demonstration scenes, preferring body-linked face detections when available. They are not a random accuracy sample. No real-world visit time or automatic identity confirmation is added.

Enrollment still derivatives
Official Neutral and Smile images from Still.tar.xz are used with their published dataset subject IDs. Reference portraits are resized and cropped from those still images. Names such as '출입 인물 01' are dataset aliases, not inferred real names. The original stills, local face galleries, and derived enrollment portraits remain private. Query video frames are separate from these enrollment stills.
