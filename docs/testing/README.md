# 인물 추적과 기록 질의 검증 준비

2026년 11월 8일에 추가 기능 검증용 보행자 영상 7개와 공식 정답 자료를 수집했다. 실제 테스트 영상의 출처는 MOTChallenge의 MOT15 및 MOT17이다. 영상은 약 4분 16초, 4,057프레임이며 원본 동영상 합계는 약 87MB다.

영상과 정답 파일은 이 컴퓨터의 `evidence/private/tracking-samples`에 보관한다. 출처의 이용 조건을 기록했고 미디어는 Git이나 운영 서버에 자동 업로드하지 않는다. 파일별 출처와 SHA256은 `evidence/tracking-samples/collection.json`에서 확인한다.

| --- | --- | --- | --- |
| PETS09-S2L1 | 약 114초 | 고정 카메라의 여러 사람 이동과 교차 | 설정 조정 |

공식 배포 페이지는 https://motchallenge.net/data/MOT15/ 및 https://motchallenge.net/data/MOT17/ 이다. 원 제작자와 이용 조건은 `video-sources.json`에 기록했다.

## 현재 확인한 범위

수집 도구를 WSL Ubuntu의 프로젝트 가상환경에서 실행했다. 영상 전체를 OpenCV로 디코딩해 프레임 수, FPS, 크기를 공식 메타정보와 비교했고 정답 ZIP의 CRC와 정답 좌표를 확인했다. 각 영상의 처음과 중간, 마지막 프레임에서는 원본과 정답 상자를 나란히 확인했다.

수집한 원본 영상에는 정답 상자가 그려져 있지 않다. 검출기에는 원본만 입력한다. 정답을 그린 검토 이미지는 입력으로 쓰지 않는다.

기존 YOLOv5 검출기에 TUD-Campus 원본 영상을 입력해 71프레임 전체의 실행과 사람 검출 출력을 확인했다. 이 결과는 영상 입력과 검출 실행 확인이며 새 인물 추적이나 RAG의 정확도 검증 결과가 아니다.

## 구현 후 측정 방법

1. 사람 검출은 정답 상자와 예측 상자를 프레임별로 대응시켜 누락과 오탐을 센다. MOT의 무시 대상과 정답 유효 표식을 반영한다.
2. 추적은 정답 사람 번호와 예측 추적 번호를 비교해 번호 변경, 추적 단절과 IDF1을 측정한다. 사람 번호는 영상 안에서만 의미가 있다.
3. 통과 집계는 모델을 실행하기 전에 고정할 가상 기준선과 방향 정의에 따라 정답 궤적을 검토해 별도 사건 정답표를 만든다. 예측과 정답 사건은 사람, 방향, 시각을 함께 비교해 누락과 중복을 센다. 이동 카메라 영상의 고정선 통과 수를 일반 출입 집계 성능에 합산하지 않는다.
4. 특징 검색은 선명한 인물 예제를 골라 상의와 하의 색, 가방 등 눈으로 확인한 정답을 별도 표시한다. 정답을 만들 수 없는 특징은 확인 불가로 남긴다.
5. 유사 인물 검색은 같은 영상의 시간적으로 떨어진 사진을 질의와 후보로 분리한다. 동일인과 다른 사람의 정답은 공식 번호로 확인하며 모르는 사람이 포함된 경우도 시험한다. 이 시험은 다른 날짜에 같은 사람이 재방문했는지 검증하는 시험으로 취급하지 않는다.
6. 기록 질의는 별도 검증 DB에 정답 이력을 넣고 날짜 경계, 통과 횟수, 촬영 중단, 자료 없음, 모호한 사람 지칭을 포함한 질문 정답표를 만든다. 실제 영상의 상대 시각을 가상 날짜에 배치할 경우 가상 날짜임을 명시한다. 답변의 숫자와 날짜, 근거 기록 번호를 실제 DB 조회 결과와 비교한다.
7. 실제 LLM API 호출과 화면 확인까지 검증한 후에 RAG 구현 완료로 기록한다. API 없이 정답 DB만 조회한 결과와 구분한다.

설정 조정용 영상과 최종 검증용 영상은 출처 단위로 분리한다. 같은 영상의 잘라낸 구간, 저조도 변형, 검출기별 DPM/FRCNN/SDP 버전을 서로 독립적인 검증 자료로 세지 않는다. 최종 검증 결과를 보고 설정을 바꾸면 해당 자료는 더 이상 미사용 최종 검증 자료로 취급하지 않는다.

## 정확도를 아직 판정할 수 없는 내용

공식 자료는 사람 상자와 영상 내 사람 번호를 제공한다. 의류 정답, 우리 서비스의 기준선 통과 사건, 실제 촬영 날짜와 날짜를 넘긴 동일인 연결은 제공하지 않는다. 이 자료만으로 다른 날짜의 동일인 판별 정확도가 검증됐다고 보고하지 않는다.

수집 영상은 강의에서 요구하는 실물 웹캠 실행 증빙을 대신하지 않는다. 현재 확보한 것은 테스트 입력과 공식 정답이며 새 추적과 특징 추출, RAG는 구현 후 성능을 측정한다.

## 재현 명령

Windows 소스 폴더를 WSL에서 실행한다.

```bash
cd /mnt/c/Users/1/mobile_web_service/common02
PY=$HOME/.venvs/mobile_web_service_02/bin/python
$PY tools/collect_tracking_samples.py
$PY tools/smoke_tracking_sample.py
```

첫 명령은 공식 원본을 내려받아 검사한다. 두 번째 명령은 이미 구성한 CPU YOLO 환경에서 짧은 원본 영상 전체를 검출한다. 모델 학습은 하지 않는다.
