# 동일인 연결 실험

2026년 11월 8일에 기존 보행자 영상과 별도로 Celeb-reID-light의 공식 query 및 gallery 사진을 확보했다. 이 자료는 인물별 정답 번호가 있어 서로 다른 사진이 같은 사람인지 비교할 수 있다. 원본 동영상의 영상 내 추적 번호만으로 날짜를 넘긴 동일인 연결을 검증할 수 없다는 문제를 보완하기 위한 자료다.

## 실제 확보한 자료

공식 배포처는 https://github.com/Huang-3/Celeb-reID 이다. 공식 시험 분할의 인물 100명, 등록 후보 사진 934장과 질의 사진 887장, 합계 1,821장을 사용한다. 학습용 사진 9,021장은 추출하지 않는다. 저자가 제공한 파일명 규칙으로 정답을 읽으며 모델 입력 파일명은 이미지 SHA256으로 바꾼다. 질의와 등록 후보 사이의 완전히 동일한 이미지도 검사한다.

자료는 연구용이며 재배포를 허용하지 않는다. 원본 사진, 정답 목록과 개별 특징 벡터는 Git에서 제외한 `evidence/private/identity-samples`에 보관한다. 공개 기록에는 출처와 집계 결과, 파일 무결성 및 실행 기록만 남긴다.

## 모델과 정답의 분리

특징 추출 함수에는 이미지 내용과 모델 설정만 전달한다. 정답 인물 번호와 원본 파일명은 전달하지 않는다. 인물 이름을 물어보는 언어 모델 호출도 사용하지 않는다.

등록 사진은 확인된 등록 자료라는 실험 조건으로 인물 프로필에 묶는다. 질의 사진의 정답은 비교 결과를 채점할 때만 사용한다. 원 제작자의 MSMT17 사전 학습 OSNet-AIN 모델을 사용하며 프로젝트에서 모델을 학습하거나 Celeb-reID 학습 사진으로 미세 조정하지 않는다. 모델 소스와 체크포인트의 출처, 버전 및 SHA256을 기록한다.

## 실험 구분

첫 번째 실험은 모든 질의 인물이 등록 후보에 포함된 상황에서 올바른 인물을 첫 번째 또는 상위 후보로 찾는지 측정한다. 이 결과는 후보 검색 성능이며 자동 연결의 안전성을 뜻하지 않는다.

두 번째 실험은 등록되지 않은 인물을 포함한다. 인물 단위로 설정 조정용 40명과 별도 평가용 60명을 나눈다. 조정용은 등록 30명과 미등록 10명, 평가용은 등록 45명과 미등록 15명으로 구성한다. 인물 분할은 고정된 해시 순서로 결정한다.

유사도 기준과 첫 후보와 두 번째 후보의 차이 기준은 조정용 자료에서만 선택한다. 잘못된 연결을 줄이기 위해 조정용 연결 정밀도 99% 이상과 미등록 질의의 오연결률 1% 이하를 실험 목표로 둔다. 이 수치는 실제 성능을 보장하는 표현이 아니며, 표본 수와 실제 정답 및 오답 수를 함께 기록한다.

평가에서는 실제 연결 정밀도, 올바르게 연결된 등록 질의 비율, 미등록 인물의 오연결률과 보류 수를 모두 공개한다. 전부 보류해 오연결만 없애는 결과는 성공으로 처리하지 않는다. 실험의 자동 연결 판정은 연결 정밀도 99% 이상, 올바른 연결 범위 50% 이상, 미등록 오연결률 1% 이하를 동시에 충족하는지 확인한다. 이것은 실험용 제안 기준이며 수업이 지정한 평가 점수가 아니다.

## DB 저장 실험

비교 결과는 운영 Django와 분리된 로컬 SQLite DB에 넣는다. 사진의 고유 번호, 연결 후보 프로필, 유사도, 자동 후보 또는 보류 상태를 저장한다. 같은 고유 번호를 두 번 전송해도 기록이 늘어나지 않는지, 존재하지 않는 프로필을 참조하지 않는지, 자동 결과가 확인 완료로 둔갑하지 않는지 검사한다.

DB 실험의 날짜는 명시적인 가상 시각이다. 원 자료에는 실제 촬영 날짜와 실제 출입 횟수가 없으므로 이 실험을 실제 방문 횟수 검증이라고 부르지 않는다. 사진 비교 결과의 저장과 중복 반영 방지를 확인하는 격리 실험이며 운영 서비스의 API와 모바일 화면 통합 검증은 별도로 필요하다.

## 결과 확인

2026년 11월 8일 WSL Ubuntu의 CPU 환경에서 실제 사진 1,821장의 특징을 추출하고 비교했다. 특징 추출에는 약 112초가 걸렸다. 모델 학습은 수행하지 않았다.

| 측정 항목 | 실제 결과 |
| --- | --- |
| 전체 100명 중 첫 후보가 정답인 질의 | 887장 중 85장, 9.58% |
| 별도 평가 질의 | 등록 인물 397장과 미등록 인물 136장, 총 533장 |
| 자동 연결 기준을 넘긴 질의 | 22장 |
| 연결 정답과 오답 | 정답 10장, 오답 12장 |
| 연결한 결과의 정밀도 | 45.45% |
| 등록 인물 질의 중 올바르게 연결한 비율 | 397장 중 10장, 2.52% |
| 미등록 인물을 기존 인물에 잘못 연결한 비율 | 136장 중 7장, 5.15% |
| 보류한 질의 | 511장 |
| DB에 같은 자료를 두 번 반영한 결과 | 첫 반영 533행, 두 번째 반영 후에도 533행 |

조정용 354장에서는 연결 기준을 넘긴 5장이 모두 정답이었지만, 인물이 겹치지 않는 별도 평가 자료에서는 오답 12건이 발생했다. 조정용 결과만 보고 자동 연결을 승인할 수 없다는 점을 확인했다. 사진 비교와 격리 DB 저장 절차는 실행됐으나 동일인 자동 연결의 성능 기준은 통과하지 못했다. 현재 모델을 운영 DB의 동일인 확정 근거로 사용할 수 있다는 결론은 내리지 않는다.

이 결과는 의상과 자세가 달라지는 연구용 사진의 비교 실험이다. 실제 웹캠 영상에서 추적한 동일 인물의 재방문 횟수와 날짜를 맞힌 결과가 아니다. 운영 Django의 인물 API, Android 화면과 RAG까지 통합한 시험도 별도로 남아 있다.

`evidence/identity-samples/collection.json`은 원본 수집과 이미지 디코딩 결과다. `evidence/identity-samples/evaluation.json`은 실제 특징 추출, 정답 비교와 DB 저장 실험 결과다. 실험 실행 성공과 자동 연결 성능 기준 통과 여부는 별도 필드로 기록한다. 결과가 기준에 못 미치면 해당 모델을 검증된 동일인 자동 연결 기능으로 보고하지 않는다.
