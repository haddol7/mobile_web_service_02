# 날짜별 관측 기록과 정면 보행 자료

관측 기록과 인물별 발견 이력을 한국 시간 기준으로 날짜별로 나눈다. 날짜 버튼으로 하루를 선택하며 전체 날짜로 돌아갈 수 있다. 분석일과 원본 촬영일은 별도 조회 기준이다. 날짜가 없는 원본은 촬영 날짜 미상으로 묶는다. 한 실행이 자정을 넘기면 각 날짜에 해당하는 사진만 각 묶음에 들어간다. 날짜별 집계는 현재 페이지의 12개 장면에 한정하지 않는다.

WSL Django 검증은 203개 테스트와 별도의 실제 HTTP 검사 15개를 통과했다. 추가된 날짜 검사는 한국 시간 자정 경계, 촬영일 미상, 날짜 선택 시 다른 날짜 탐색 유지, 페이지 경계, 인물별 이력의 날짜 구분을 확인한다. Windows 웹 검사 72개와 Android JVM 검사 40개도 통과했다. Android Emulator의 작은 화면과 일반 화면에서 네이티브 화면과 WebView를 캡처했다. 운영 검증 결과는 `evidence/ui-audit/calendar-deployment.json`에 기록한다.

정면 보행 자료는 NICTA ChokePoint의 P1E_S1 원본을 사용했다. 공식 Zenodo에서 정답 파일과 385,315,324바이트 원본을 순서대로 내려받고 게시된 MD5를 대조했다. 카메라 1과 2의 원본 이미지가 각각 2,292장 있다. 카메라 1의 첫 1,200개 제공 이미지로 만든 재생 영상에서 10장 간격으로 120프레임을 분석했다. 얼굴 검출은 84건, 몸 추적과 연결된 얼굴은 62건이다. 같은 얼굴의 반복 검출이 포함되므로 사람 수나 방문 횟수가 아니다. 기존 등록 인물에 대한 후보는 0건이며 확인되지 않은 인물은 그대로 미확인으로 남겼다. 이 검사는 미등록 보행자의 검출 사례이며 서로 다른 날의 동일인 판정 정확도를 증명하지 않는다.

실제 관측 사진 14장을 PythonAnywhere의 비공개 이력에 추가했다. 원본 촬영일은 미상으로 유지했다. 변환 영상의 시간과 원본 이미지 파일명 대응은 `evidence/history/cctv-walking-cloud.json`에 기록했다. 기존 공개 게시글, 계정, 미디어를 보존했다.

추가로 CAVIAR 통로 영상 3개와 기존 MOT17 보행 영상 2개를 확보하고 디코딩했다. CAVIAR는 384x288로 얼굴 비교에 한계가 있어 이번 정면 보행 시연에는 ChokePoint를 사용했다. 공항 원본 관제 영상이라고 표시하지 않는다.
