본문 소제목

B08 실시간 웹캠 검출

본문에 넣을 문단

2026년 11월 10일, Windows 노트북의 Acer HD User Facing 웹캠을 USB/IP로 WSL2 Ubuntu에 연결했다. /dev/video0에서 실제 프레임이 읽히는 것을 확인한 뒤, 변경하지 않은 YOLOv5 v7.0의 detect.py를 카메라 인덱스 0으로 실행했다. 원본 검출기와 공식 가중치의 SHA256이 기록된 값과 일치했다. 카메라의 기본 YUYV 형식에서 발생한 녹색 깨짐은 입력을 MJPEG로 지정해 해결했다. 640×480 실시간 프레임에서 사람의 검출 상자와 person 0.71 라벨이 표시됐고, 원본 검출기가 화면에 표시한 프레임을 증빙으로 저장했다.

그림 캡션

그림 B08 1 실제 노트북 웹캠을 입력으로 실행한 원본 YOLOv5의 사람 검출 화면

02_웹캠_증빙/웹캠_실시간_검출.png

검증 근거

- Windows x64 빌드 26200.8037, WSL 3.0.3, Ubuntu 24.04.2 LTS, WSL 커널 6.18.54.1, Python 3.12.3, PyTorch 2.6.0 CPU
- tools/run_edge.py --baseline --source 0 --device cpu --view-img --nosave --save-txt --save-conf
- 실제 실행은 webcam_mjpeg_capture.py를 통해 카메라 0번에 MJPEG를 지정하고 위 원본 실행 경로를 호출했다.
- 2026년 11월 10일 01시 40분 재촬영 정상 종료. 선택한 화면은 추론 순번 101이며 person 점수는 0.708044다. 검출값 파일이 저장된 프레임은 124개였다.
- 02_웹캠_증빙/웹캠_검증.json과 webcam-retake.log
